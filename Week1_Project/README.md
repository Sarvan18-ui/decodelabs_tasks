# To-Do List Application

## Description
This project is a simple To-Do List application developed in Python. It allows users to add tasks and view their stored tasks using lists, loops, and dictionaries.

## Features
- Add new tasks
- View all tasks
- Store tasks using Python data structures
- Menu-driven interface

## Technologies Used
- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements

## How to Run

1. Open terminal.
2. Navigate to the project folder.
3. Run:

python todo.py
