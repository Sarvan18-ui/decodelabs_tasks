# Random Password Generator

## Description
This project generates secure random passwords using Python's built-in modules. Users can specify the password length, and the program creates a password containing letters, numbers, and special characters.

## Features
- Generate random passwords
- User-defined password length
- Includes letters and numbers
- Includes special characters
- Ensures at least one number and one special character

## Technologies Used
- Python
- random module
- string module
- Loops
- String Manipulation

## How to Run

1. Open terminal.
2. Navigate to the project folder.
3. Run:

python password_generator.py
