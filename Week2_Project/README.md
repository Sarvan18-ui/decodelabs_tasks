# Expense Tracker

## Description
This project is a simple Expense Tracker built using Python. Users can add expenses, view all expenses, and calculate the total amount spent.

## Features
- Add expense amounts
- View all expenses
- Calculate total expenditure
- Continuous data entry

## Technologies Used
- Python
- Lists
- Loops
- Accumulators
- Conditional Statements

## How to Run

1. Open terminal.
2. Navigate to the project folder.
3. Run:

python expense_tracker.py
