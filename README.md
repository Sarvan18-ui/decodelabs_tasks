# DecodeLabs Python Internship Projects

This repository contains Python projects completed during the DecodeLabs Industrial Training Program.

## Projects

### Project 1: To-Do List Application

A simple task management program that allows users to add and view tasks using Python lists and loops.

**Concepts Used:**

* Lists
* Loops
* Dictionaries
* User Input

### Project 2: Expense Tracker

A Python application that records expenses and calculates the total amount spent.

**Concepts Used:**

* Accumulators
* Mathematical Operations
* Lists
* Loops

### Project 3: Random Password Generator

A password generation tool that creates secure passwords using letters, numbers, and special characters.

**Concepts Used:**

* Random Module
* String Module
* String Manipulation
* Loops

## Technologies Used
